# DESCoplite

> 面向低共熔溶剂（Deep Eutectic Solvent, DES）的自动化研究 Harness。

DESCoplite 将文献采集、PDF 理解、数据治理、数据库入库、性质预测与配方生成集成成自动化工作流。目标是实现Agent辅助下的DES 数据搜集与建模以及实验试错成本。

## 工作流

```text
文献检索 → PDF Agent 抽取 → 数据治理与入库 → 性质预测与配方生成 → 候选筛选
```

## 功能模块

### Step 1：文献采集与 PDF 理解

- 自动化文献检索与 PDF 获取
- Agent 处理 PDF：文本结构化提取、多模态图表理解
- 小模型预筛选 + 轻量微调 VLLM 进行图表数据提取
- 保留原文证据、页码/图表编号，保证可追溯性。

### Step 2：数据治理与入库

- 化学实体、单位与实验条件标准化
- 去重、冲突检测与异常标记
- 来源追溯与数据版本管理

### Step 3：性质预测与配方生成

- 生成模型进行目标 DES 配方生成
- DES 性质预测，Agent自动建模
- 适用域判断
- 候选配方排序、筛选与优化
