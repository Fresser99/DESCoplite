# DESCoplite

> 面向低共熔溶剂（Deep Eutectic Solvent, DES）的文献数据自动化 Harness。

DESCoplite 将文献采集、PDF 理解、数据治理、数据库入库、性质预测与配方生成串联为可编排、可追溯的自动化工作流。目标是降低 DES 数据整理与建模成本，并让每个数据点和预测结果都有来源可查。

当前状态：**早期设计阶段**。

## 工作流

```text
文献检索 → PDF Agent 抽取 → 数据治理与入库 → 性质预测与配方生成 → 候选筛选
```

当预测发现数据缺口时，可触发下一轮文献补采。

## 功能模块

### Step 1：文献采集与 PDF 理解

- 文献检索与 PDF 获取
- Agent 处理 PDF：文本结构化提取、多模态图表理解
- 小模型预筛选 + 轻量微调 VLLM 进行图表数据提取
- 保留原文证据、页码/图表编号与抽取置信度

### Step 2：数据治理与入库

- 化学实体、单位与实验条件标准化
- 去重、冲突检测与异常标记
- 来源追溯与数据版本管理

### Step 3：性质预测与配方生成

- 生成模型进行 DES 配方生成
- DES 性质预测与不确定度量化
- 适用域判断
- 候选配方排序、筛选与优化

## 特点

- 可编排、可追溯、可复现
- 关键节点支持人工审核
- 文献源、模型与数据库均可插拔
